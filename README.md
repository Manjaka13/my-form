# MyForm
This is a reusable web component library built using Vue 3.5, Typescript and Vite. It implements various usefull components such as input, switch, button...

#### Installation

``
npm install
``

#### Run documentation

``
npm run dev
``

#### Build

``
npm run build
``

#### How to use
After build it will render a `dist` folder, just import `my-form.es.js` and `my-form.css` in your project, you can view the documentation in `npm run dev` to see how each component works.

#### Note
If you use the web components in plain HTML/JS it may warning you that process is not defined. So you just need to define it in JS like this:

`window.process = {};`
